# Spatial Econometric Optimization of EV Charging Infrastructure

### A Commuting-Network Spatial Durbin Model & Counterfactual Budget Reallocation across 356 Municipalities (Norway, 2016–2023)

---

## Executive Summary & Key Results

Public capital allocation for electric vehicle (EV) charging infrastructure typically relies on local density heuristics, ignoring spatial network diffusion. Using a panel of all 356 Norwegian municipalities (2016–2023), this project estimates a **two-way fixed effects Spatial Durbin Model (SDM)** to measure network spillovers across inter-municipal commuting corridors.

### Core Findings & Quantitative KPIs

* **The Spillover Dominance:** Across commuting networks ($`W_3`$), the spatial spillover effect ($`\hat{\theta} = 0.00274`$, $`p < 0.001`$) is **2.26× larger** than the direct local effect ($`\hat{\beta} = 0.00121`$). Infrastructure value is transmitted through daily transit corridors, not isolated local borders.
* **Lag Identification:** The spillover effect strengthens rather than dissipates under a 1-year lag ($`t-1`$), rejecting reverse causality and confirming an adoption diffusion mechanism over time.
* **Systemic Misallocation:**
  * **Bergen** is consistently **oversupplied** relative to its diffusion value across every year of the panel (+4.34 standard deviations above network parity in 2023).
  * **Oslo** is the single **most undersupplied** municipality in Norway (−7.60 standard deviations), despite holding the 2nd-largest physical charger stock, due to extreme commuting-network centrality (diffusion multiplier 14.42 standard deviations above the mean).
* **The Zero-Dollar Optimization (Counterfactual):** Solving a greedy budget-constrained reallocation of Norway's observed 2023 infrastructure stock (75,452 kW) generates an estimated **+2.54% to +4.17% gain in national EV adoption at zero additional fiscal cost**.

## Data & Econometric Architecture

### 1. Data Ingestion & Integration

* **EV Registrations & Demographics:** Statistics Norway (SSB) municipal panel datasets (2016–2023).
* **Charging Infrastructure:** NOBIL Norwegian charging station database (geocoded charging points, power capacities, connector types).
* **Spatial Topologies:** Kartverket administrative boundary shapefiles for Norwegian municipalities.

### 2. Spatial Weight Matrix

Rather than relying on naive Euclidean distance or shared borders, the primary spatial weights matrix ($`W`$) models a row-standardized, directed economic commute graph derived from inter-municipal commuter flows. This isolates labor transit corridors as the transmission vector for technological peer effects.

### 3. Econometric Architecture & Pipeline

The project is structured across a four-stage mathematical pipeline, translating raw spatial panel data into a budget-constrained policy optimization.

#### Stage 1: The Spatial Durbin Model (SDM)

Estimates the core network spillovers with municipal and year fixed effects. To model bounded proportion data $`[0, 1]`$ without arbitrary boundary clamping, the dependent variable applies a square-root variance-stabilizing transformation ($`y_{it} = \sqrt{p_{it}}`$):

```math
Y_{it} = \rho \sum_{j} w_{ij} Y_{jt} + X_{it} \beta + \sum_{j} w_{ij} X_{jt} \theta + \mu_i + \lambda_t + \varepsilon_{it}
```

#### Stage 2: The Diffusion Multiplier

The raw parameters are transformed into a total-effect spatial multiplier matrix, capturing the full endogenous feedback loop of a charger placed at node $`j`$. The column sums represent the total system-wide adoption generated by a marginal infrastructure unit:

```math
M = (I - \rho W)^{-1}(I \beta + W \theta)
```

```math
\mathrm{Multiplier}_j = \sum_{i} M_{ij}
```

#### Stage 3: The Misallocation Index

Identifies infrastructure inefficiency by calculating the divergence between a municipality's standardized observed charging capacity ($`\tilde{K}_{it}`$) and its standardized network diffusion value ($`\tilde{M}_i`$):

```math
\mathrm{Misallocation}_{it} = \tilde{K}_{it} - \tilde{M}_i
```

**Stage 4: Counterfactual Reallocation (Non-Linear Optimization)**  
A discrete-increment greedy algorithm reallocates capacity to equalize marginal network returns across nodes. Because the model operates on non-linear transformations ( $y = \sqrt{p}$ and $x = \mathrm{asinh}(kW)$ ), each step updates marginal gain via analytical chain-rule derivatives:

The full endogenous network feedback is re-evaluated at each increment through:

```math
\hat{M} = (I - \hat{\rho} W)^{-1}(I \hat{\beta} + W \hat{\theta})
```
